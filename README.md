# Rizky Builds

Personal headquarters for portfolio, ventures, services and writing. Static ES modules, CSS and HTML; no build dependencies or backend.

## Run locally
`python -m http.server 8000` from the repository root, then open `http://localhost:8000`.

## Edit
- `src/content.js`: projects, services, skills.
- `index.html`: biography, sections, metadata, verified contact links.
- `src/style.css`: design tokens, responsive layout, dark mode.
- `src/app.js`: filtering, theme, brief copying, profile download and local time.
- `docs/`: publishing and content policies.

## Publish
GitHub Pages: enable Settings → Pages → Deploy from a branch → main / (root). No email, analytics, or form backend is configured. The contact form only copies a brief locally; it never sends data.

Design inspiration: user-supplied Kedhar sidebar portfolio template; independently implemented layout and illustration. No template source copied. Project names and descriptions should be reviewed before public release.
